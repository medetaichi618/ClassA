## 4. 考察問題回答
* **問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？**
  * **答**：因為原始資料中的人數 `"4"` 是字串（String）型別。在 Python 中，字串無法直接參與數學除法運算（例如總金額除以人數會報錯）。必須先使用 `int()` 函式將其轉換為整數（Integer）型別，才能正確進行算術運算並計算出每人應付費用。

* **問題二：如果先扣折扣券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**
  * **答**：
    * 若先扣折價券（$1200 - 100 = 1100$），再計算 10% 服務費（$1100 \times 1.1 = 1210$），第一組的應付總額會變成 **1,210.00 元**（而題目規定的正常計算結果是 1,220.00 元）。
    * **原因**：餐廳的服務費通常是以原始餐點消費金額（未折價前）為基準來計算的，而不是折價後的金額。如果先扣折價券再算服務費，會導致計算基数變小、服務費變少，不符合一般餐飲業的計費邏輯與本題規定的計算順序。
