## 考察問題

**1. 測試一整理後的桌遊串列明明有 4 筆，為什麼算錢只算 3 人？直接拆成 `list` 跟轉成 `set`，各自留住了什麼、又失去了什麼？**

整理完的桌遊名單是 `['amy', 'ben', 'amy', 'cora']`，雖然有 4 筆，但 `amy` 其實報了兩次[cite: 12, 13]。規則是同一場活動同一個人只算一位、只收一次錢[cite: 8]，所以算費用的時候是 3 個人（`3 * 120 = 360` 元）[cite: 12, 13]。
直接用 `split(",")` 拆成 `list` 的好處是**原本報名的先後順序跟重複幾次都還在**，看得出誰重複報了；缺點是不能直接拿來當不重複人數算錢[cite: 9, 11]。轉成 `set` 之後**重複的被清掉了，也能直接用 `&`、`|`、`-` 做集合比對**，但原本的順序跟重複次數就沒了[cite: 10]。

**2. 測試三兩場加起來只有 3 個不同的人，為什麼報名人次是 6，總應收還是 600 元？**

測試三兩邊去重後都是 `{'amy', 'ben', 'cora'}`，等於桌遊集合跟電影集合完全一樣（交集、聯集都是這 3 人，兩個方向的差集都是空的 `[]`）[cite: 10, 13, 15]。因為這 3 個人兩場都報了，所以桌遊有 3 人、電影也有 3 人，加起來報名人次就是 $3 + 3 = 6$ 人次[cite: 10, 13, 15]。收費是看各場不重複人數分開算：桌遊 $3 \times 120 = 360$ 元，電影 $3 \times 80 = 240$ 元，合起來就是 $360 + 240 = 600$ 元[cite: 10, 12, 13, 15]。
